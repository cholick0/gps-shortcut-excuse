## The entry

> I took you to the wedding AND the lake. The map never said they were separate events.

85 characters, one line — the GPS talking, smug and defensive, blaming the map.

## Run it

```sh
node main.ts   # requires Node 22+
```

Writes the excuse to `/output/entry.txt` and verifies it byte-for-byte against the gate (1–200 characters, single line, not only whitespace).
